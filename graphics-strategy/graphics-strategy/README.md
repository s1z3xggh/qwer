# Графика — шаблон «Стратегия»

Учебное приложение по МДК 2.2 «Инструментальные средства разработки».

## Возможности

- Фигуры: смена цвета и размера по щелчку, вращение прямоугольника и сброс.
- Холст 2D: рисунок на Canvas, выбор цвета и толщины линий.
- Модель 3D: загрузка куба из OBJ, вращение мышью, масштабирование колесом, перемещение стрелками после щелчка по сцене.

## Оптимизация

Шаблон «Стратегия» разделяет алгоритмы обработки фигур:
`ShapeAction` — интерфейс, `ColorAction` и `ResizeAction` — реализации,
`ShapeController` — контекст. Общий обработчик делегирует действие выбранной стратегии.
Фоновое изображение Canvas создается один раз и используется повторно.

## Требования

JDK 17, Maven 3. Для запуска нужна графическая среда; для отображения модели — поддержка JavaFX 3D.
При первой сборке нужен интернет для получения зависимостей Maven.

## Запуск

Откройте терминал в папке с `pom.xml`:

```sh
mvn test
mvn clean javafx:run
```

Также проект можно открыть как Maven-проект в IntelliJ IDEA.

## Проверка

Выполнено 9 автоматических тестов загрузчика OBJ и стратегий; все прошли.
Визуальная работа интерфейса и 3D-сцены в среде подготовки не проверялась.

## Структура

- `pom.xml` — настройки сборки и зависимости.
- `src/main/java` — исходный код приложения.
- `src/main/resources/models/cube.obj` — трехмерная модель.
- `src/test/java` — автоматические тесты.
- `.gitignore` — исключение результатов сборки и настроек IDE.
